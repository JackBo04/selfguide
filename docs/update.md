# 重复安装与升级

升级只更新选定 skill 的程序和规则。写作模块在两个浏览器版本中都可用，绘图和实验迭代暂为空位。选择模块无需重复安装，也不需要为每个模块安装一份 skill。

## 在服务器终端更新 skill

在 Codex／VS Code 当前连接的服务器终端中，进入现有 SelfGuide 仓库：

```bash
git pull --ff-only
python3 tools/install.py local --update
```

浏览器在服务器时将 `local` 换成 `server`。发行 ZIP 用户先解压新包，在新包根目录运行安装命令即可，不必运行 Git。若仓库有自己的改动，先由 Agent 保留并合并，不强制重置。

原来通过 `$selfguide` 调用的单机部署，可保留同一名称：

```bash
python3 tools/install.py server --name selfguide --update
```

安装位置不是默认的 `~/.agents/skills/` 时，加上 `--skills-dir <原来的发现目录>`。安装路径若是符号链接，更新其实际目标，保留链接本身；不要同时给一个目标运行多次更新。

- 相同发行内容重复安装会提示 `Already up to date`，不另建副本或备份。
- 有差异时，`--update` 先将现有安装备份到 `~/.local/share/selfguide/skill-backups/`，再替换发行文件，保留额外本地文件。可用 `--backup-dir <目录>` 指定备份位置。
- 对发行文件的个人修改不会自动合并，原样保存在备份中。让 Agent 把仍需保留的定制合入新版；不要把备份里的旧模块规则整份覆盖回来。
- 独立的浏览器登录目录、桥接配对配置和任务目录保持原处。升级不自动重新初始化、登录或启动第二个服务。
- 开启新的 Codex 会话以加载新规则。运行中的桥接进程仍使用已经加载的旧代码；需要代码升级时，先确认原 job 的状态，再在原终端停止桥接并用同一配置重启。服务器 Chrome 无需随 skill 更新而重启。
- 服务器版运行依赖的 `package-lock.json` 有变化时，在安装目录的 `runtime/server-browser/` 执行 `npm ci`。安装器会保留已有 `node_modules`，但不会自动更新依赖。

## 更新浏览器扩展

两种版本都需让浏览器加载新版扩展。服务器版更新安装目录的 `extension/`；本地版还需更新自己电脑上的固定扩展目录。

1. 从最新源码或对应版本 ZIP 取得 `extension/`，更新原来的固定扩展目录，保持路径不变；服务器版安装器已完成这一步。
2. 原任务有未确认操作时先让 Codex 查询并解决原 job，再暂停扩展收发。
3. Chrome 打开 `chrome://extensions`，Edge 打开 `edge://extensions`，找到 SelfGuide，点击“重新加载”。
4. 新版扩展在下一次操作时自动重接已有任务标签页的文字通道，无需刷新页面，保留草稿与生成中的回复。确认 SSH 转发仍在运行，复用已有连接。任务窗口无需重新配对；只有原连接缺失时才在项目入口点“连接浏览器”。

同一扩展和目录通常会保留原配对信息，也无需退出 ChatGPT。若改了目录、扩展 ID 或浏览器配置，使用原服务器配对信息重新绑定；不要因此重新生成配对码。网站要求登录时再正常登录。

## 交给 Agent 的更新指令

```text
请更新我现有的 SelfGuide：
https://github.com/JackBo04/selfguide

先读取 docs/update.md，识别原安装位置、调用名和浏览器版本。
获取新版，用 --update 更新到原位置；原来叫 selfguide 的保留这个调用名。
保留登录、配对、任务记录和需要的个人定制，常规步骤直接执行。
写作模块启用；绘图和实验迭代先保持空位。
如果我使用本地浏览器，给我原扩展目录的更新与重新加载步骤。
完成后告诉我当前调用方式和实际验证结果。
```

从 v0.4.0 服务器桌面流程升级时，还需按 [服务器指南](server-browser.md#连接-dom-文本桥接) 首次配置 DOM 桥接和扩展；保留原浏览器与任务记录。旧轮次收发先完成或恢复，再迁移到新任务窗口。

## 恢复上一版

使用安装器输出的备份路径。先结束或记录当前交接，保留新版目录作为另一份备份，再把旧备份复制回实际安装位置；原路径是符号链接时保留链接。恢复相应桥接进程和扩展版本后，在新 Codex 会话中继续原任务。恢复 skill 不需要还原或删除浏览器登录资料。
